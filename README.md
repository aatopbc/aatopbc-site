# aatopbc-site

Sitio web de la Asociación de Anfitriones y Tour Operadores de Baja California (AATOPBC).

Next.js 16 · React 19 · Tailwind CSS v4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # build de producción
```

El contenido está en `src/lib/` (`data.ts`, `destinos-data.ts`, `categorias-data.ts`, `socios-data.ts`, `mesa-directiva-data.ts`) y las imágenes en `public/images/`.
